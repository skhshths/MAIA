About MAIA

MAIA (Medical AI Assistant) is a small web app that runs a set of image classifiers over medical scans: brain MRIs, chest and bone X-rays, and retinal photos. You upload an image, pick the model that matches it, and MAIA gives back its best guess with a confidence score for every possible answer.

Each model is a ResNet-18 network, fine-tuned for a single task and exported to ONNX so it runs anywhere, from a laptop to an NVIDIA Jetson. Inference happens locally; nothing is sent to an outside service.

How to read a result

The big number is how much weight the model puts on its top answer. It isn't a probability that the diagnosis is right. A model can be confidently wrong, especially on an image unlike the ones it learned from. If the top two answers are close, MAIA will flag it.

Every model will give an answer for any picture you give it, even a photo of an apple. Always pick the model that matches the scan.

Your images

Uploaded images are saved in the uploads/ folder on the machine running MAIA, and the last 15 results show up on the admin dashboard. Anyone with access to that machine can see them, so don't upload anything you wouldn't want stored.

Please note

MAIA is a learning project. It has not been clinically validated and must not be used to make medical decisions. If you're worried about a scan, talk to a doctor.
